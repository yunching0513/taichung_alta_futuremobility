# 臺中：都市空間與未來移動

臺中市的住宅、移動、人口與土地使用，收成一份指得出出處的資料集。
空間單位是29個行政區，不是縣市。

## 為什麼另開一個 repo

[`yunching0513/housing`](https://github.com/yunching0513/housing) 處理的是全國22縣市的住宅供需，
臺中在那裡只是22分之一。唯臺中的問題不完全是住宅問題：
**它是六都之中所得成長最快、自有率卻最低的城市，同時空屋率六都最高。**
這三件事同時成立，靠住宅一個切面解釋不了。

移動那一面同樣如此。臺中全市的日夜間人口比0.997，日間3,043,848人、夜間3,052,296人，
看起來是一個通勤圈與市界幾乎重合、自給自足的城市。
唯拆到區級，從外埔區的0.819到西屯區的1.198，全距0.379。
**全市那個接近1的漂亮數字，是兩組方向相反的失衡互相抵銷出來的。**
本 repo 因此獨立出來：範圍比住宅寬，尺度比全國細。

分工是這樣：全國層級的住宅比較留在 `housing`，臺中的區級與跨部門資料放這裡。
兩邊重疊的數字（例如社宅戶數、租金中位數）以 `housing` 的解析結果為準，本 repo 不另算一份。

## 兩張圖疊起來看：29個區的空屋與通勤

普查空屋率（民國109年）與日夜間人口比（電信信令，民國112年11月），兩者的區級極端值：

| 區 | 空屋率 | 日夜比 | 住宅 | 家戶 |
|---|---|---|---|---|
| 西屯區 | 19.05% | 1.198 | 114,057 | 98,068 |
| 中區 | 28.57% | 1.168 | 9,415 | 10,399 |
| 西區 | 15.64% | 1.164 | 57,573 | 45,148 |
| 清水區 | 19.68% | 0.864 | 31,410 | 26,973 |
| 北屯區 | 11.76% | 0.852 | 117,511 | 101,548 |
| 外埔區 | 9.51% | 0.819 | 9,304 | 9,483 |

空屋率最高的中區28.57%與最低的龍井區7.15%相差21.4個百分點，
而臺中市與臺北市之間的市際落差只有3.90個百分點；**區內落差是市際落差的五倍以上。**

直覺上會猜「白天聚集人的地方，就是晚上空著的地方」，唯資料不支持這個猜測：
29個區的空屋率與日夜比的相關係數只有0.282，是弱相關。
西屯區與中區確實同時具備高日夜比與高空屋率，
可是清水區的空屋率19.68%配上0.864的日夜比，方向剛好相反。
**這代表臺中的空屋至少有兩種成因，用同一套解釋會失真**，
而區分它們需要更細的資料：屋齡、建物型態、產權年份、以及通勤的起訖對。
這是本 repo 想回答的第一個問題。

還有一個現象值得追：中區的住宅9,415宅少於家戶10,399戶，
烏日區、龍井區、大肚區、外埔區也是同樣的方向。
住宅比家戶少、空屋率卻不低，這兩件事要並存，只可能是存量的位置與需求的位置對不上。

## 目前產出

```
python3 scripts/prep_districts.py    # data_TW/from_housing/          → data/tc_districts.json
python3 scripts/prep_rail.py         # data_TW/from_tdx_transit_twin/ → data/tc_rail.json
python3 scripts/build.py             # data/ + src/                   → dist/index.html
```

`dist/index.html` 是單一檔案、點開就能看，五節：

| 節 | 內容 |
|---|---|
| 01 Commuter Flow | 全市日夜間人口比0.997與29區的全距0.379 |
| 02 The City Breathing | 滿版大型地圖。六個圖層 × 四個時段 × 平假日，可疊軌道路網 |
| 03 Housing Base | 住宅、家戶、空屋率、常住人口、屋齡40年以上，五項切換著色 |
| 04 Weak Correlation | 空屋率×日夜比散布圖，相關係數0.282 |
| 05 Accessibility | 公共運輸站點×社宅基地。**這一層還沒有資料**，缺什麼寫在頁面上 |

第02節的軌道疊圖分臺鐵與高鐵兩系統：西部幹線（山線）、西部幹線（海線）實線，
成追線虛線，高鐵另一色。臺中境內共23個臺鐵車站，依本研究從線形算出的三級標示：
與高鐵線相距400公尺內的轉乘站（新烏日）、山海線的交會站（追分、成功）、一般站。
**這個分別不是臺鐵官方的站等**，官方站等分特等至招呼共六級，來源檔沒有那個欄位。
臺中捷運綠線也不在來源檔裡，兩者都列在待收清單。

視覺沿用 VZT 風格指南：單一強調色（石灰黃綠 #C8D400）、大量留白、
超細字重配超大字號、中英並陳。刻意只做淺色一套，深色版會把「留白為主體」這件事推翻。
唯一的外部請求是 Google Fonts，字型連不到時有系統字型後備，版面仍然成立。

## 資料夾結構

```
data_TW/    原始檔。政府網站下載的原樣，不修改
data/       解析後的中間檔（JSON），版面唯一的資料來源
scripts/    解析程式，一支對一份中間檔
src/        版面模板
docs/       資料來源清單與方法筆記
```

方向是單向的：`data_TW/` → `scripts/` → `data/` → `src/`。
版面不直接讀原始檔，解析程式不回頭改版面。

## 三條規矩

1. **數字要有出處。** 版面上的統計數字一律從 `data/*.json` 讀，不硬編進模板。
   來源更新的那一天，手寫的數字會靜靜地變成錯的，而且沒有人會發現。
2. **算不出來就給 `null`。** 樣本不足、定義斷掉、期別對不上的時候，寧可留白並標明原因，
   也不要給一個看起來像數字的東西。
3. **定義變過的地方要標出來。** 例如主計總處在民國112年把「建坪」改成不含陽台與露臺，
   臺中的每戶建坪中位數因此從111年的45坪掉到112年的42坪；那不是房子變小。
   跨過這種斷點畫出來的線會很好看，也會是錯的。

期別也一樣要標。上面那張表裡，空屋率是民國109年、信令是112年11月、
社宅進度是115年7月，三個不同的時間點；同一格內的比較成立，跨格比較要先看期別。

## 待收的資料

見 [`docs/sources.md`](docs/sources.md)。目前最擋路的兩份：

**公共運輸站點。** 交通部TDX需要申請帳號取得 client_id 與 client_secret，
無金鑰存取回401、取token回400 `invalid_client`。
臺中市政府資料中心 `datacenter.taichung.gov.tw` 在本專案目前的網路環境下連不到，
CONNECT 被回502。兩者擇一取得之後，站點就能落圖。

**社宅基地座標。** 內政部的社會住宅興辦進度只到縣市層級的戶數，
給不出基地在哪一個區、哪一個地號；清單要向臺中市住宅發展工程處取得，
或從公告的招租資訊逐案抄。
