# 待收的資料

依「這份資料能回答什麼問題」排序，不依機關排序。
每一項都要記下**期別**與**空間單位**：臺中的資料最常見的坑，是把109年普查的區級數字
跟114年的市級數字放在同一張圖上。

本 repo 有兩條主軸：**住宅存量**與**移動**。兩者在臺中是同一個問題的兩面，
因為29個區的空屋率與日夜間人口比只有0.282的弱相關，
表示「空著的房子」與「白天沒人的地方」不是同一批區，
要把它們分開解釋，就得同時握有兩邊的資料。

標示說明：`✅` 已在 `housing` repo 解析完成，可直接引用；`◻` 待收；`⚠` 需先確認取得方式。

---

## 一、住宅存量與空屋

| | 資料 | 機關 | 期別／單位 | 能回答什麼 |
|---|---|---|---|---|
| ✅ | 人口及住宅普查 | 主計總處 | 109年／29區 | 住宅數、家戶數、空閒住宅、宅戶比、屋齡、面積級距 |
| ✅ | 低度使用（用電）住宅 | 內政部 | 98年至114下半年／區 | 用電表判定的閒置，可補普查的時間空缺 |
| ◻ | 房屋稅籍住宅資訊 | 財政部財政資訊中心 | 逐季／區 | 住宅存量、所有權人戶數、多屋族分布 |
| ◻ | 建築物使用執照存根 | 內政部營建署 | 逐月／區 | 新增供給的時間與位置，可對照空屋的形成 |
| ⚠ | 危老與都更核准案件 | 臺中市都市發展局 | 逐案／地號 | 老舊住宅的更新速度與空間分布 |

普查與用電低度使用兩套定義不同、期別不同，**不能相減、不能混用**，只能各自看方向。

## 二、住宅價格與租金

| | 資料 | 機關 | 期別／單位 | 能回答什麼 |
|---|---|---|---|---|
| ✅ | 不動產成交案件（實價登錄）租賃 | 內政部地政司 | 102年至114年／區 | 租金中位數、每坪租金、社宅包租代管與一般案件的價差 |
| ◻ | 不動產成交案件買賣 | 內政部地政司 | 逐季／區 | 成交價、屋齡、面積，可算區級的價格分布 |
| ✅ | 房價所得比與房貸負擔率 | 內政部不動產資訊平台 | 逐季／縣市 | 負擔能力。**只有縣市層級，沒有區級** |
| ◻ | 地價指數與公告土地現值 | 內政部地政司 | 逐年／區 | 土地價格的長期走勢，接得上開發預期心理 |

實價登錄的租賃申報義務主要落在租賃住宅服務業經手的案件，房東自租大多不在裡面；
臺中的申報樣本5,559筆，其中相當比例是社宅包租代管的政策價。
**相對高低可用，絕對值不宜當市場行情。**

## 三、住宅政策工具

| | 資料 | 機關 | 期別／單位 | 能回答什麼 |
|---|---|---|---|---|
| ✅ | 社會住宅興辦進度 | 內政部營建署 | 逐月／縣市 | 完工、興建中、待開工、規劃中，含中央與地方分項 |
| ◻ | 社會住宅基地清單 | 臺中市住宅發展工程處 | 逐案／地址 | 落點在哪一區、離捷運多遠、周邊有沒有學校 |
| ✅ | 包租代管媒合戶數 | 內政部 | 逐期／縣市 | 累計媒合與仍有效契約 |
| ◻ | 租金補貼核定戶數 | 內政部 | 逐年／縣市 | 三項工具（興建、包管、補貼）的相對規模 |
| ⚠ | 社宅申請與中籤倍數 | 臺中市住宅發展工程處 | 逐案 | 需求的強度。中籤率比戶數更能說明缺口 |

社宅的「規劃中」與「興建中」是兩種不同性質的承諾：**興建中的戶數改不掉，規劃中的改得掉。**
臺中的待開工加規劃中只有739戶，這一格的後續變化要逐期追。

信令資料只給每一區的日間與夜間人口總數，**給不出起訖對**：
它能告訴你北屯區白天少了多少人，答不了那些人去了哪一區。
要回答後者，得接票證或起訖調查。這是目前最大的一個缺口。

## 取得方式

- **政府資料開放平臺** <https://data.gov.tw> ：多數全國性資料集的目錄
- **臺中市政府資料開放平臺** <https://data.taichung.gov.tw> ：市級與區級資料
- **內政部不動產資訊平台** <https://pip.moi.gov.tw> ：住宅相關統計與實價登錄
- **主計總處** <https://www.stat.gov.tw> ：普查與家庭收支調查
- 標示 `⚠` 者多半沒有開放資料介面，需要向機關申請或從公告網頁逐案下載。

`housing` repo 的 `scripts/fetch_sources.py` 已經處理過憑證鏈不完整、
需要瀏覽器標頭、以及斷點續傳的問題，抓檔的部分可以直接借用那一支，不必重寫。

## 兩個先做的建議

**其一，先把29個區的基本盤補齊。** 住宅數、家戶數、空屋率、人口、屋齡五項，
`housing` repo 已經有109年普查的區級資料，可以直接接過來當底圖，
再往上疊戶籍月報的最新人口。這一步做完，臺中的問題形狀就看得見了。

**其二，追一格數字：社宅的待開工加規劃中。** 現在是739戶。
興建中的10,344戶陸續完工之後，這一格若沒有補上，臺中的社宅政策就會停在總計每千戶16.43戶，
六都最低。這一格逐月的變化，比任何論述都更能說明市府的意圖。
